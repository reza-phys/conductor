# Quality standards (global, read by every auditor)

- Every claim cites concrete evidence: a file path (+ lines), a command and its result, or a source URL.
- Numbers are reproducible: say how they were computed.
- "Done" means verified at the source (tests run, file exists, output checked) — not "should work".
- Unknowns are stated as unknowns, never filled in.
- Changes stay within the task's scope; anything else is reported, not done.
